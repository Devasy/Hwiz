## 🐛 Troubleshooting

### Problem: Processing is slow

**Check:**
- ✅ Internet connection strength
- ✅ Battery level
- ✅ Other apps running

**Try:**
- Close other apps
- Connect to WiFi
- Process fewer files at once

---

### Problem: Some files failed

**Common Reasons:**
```
❌ "File could not be read"
   → File is corrupted or encrypted
   → Try re-scanning the original document

❌ "Text not clear enough"
   → Image quality too low
   → Try taking a better photo/scan

❌ "Network error"
   → Lost internet connection
   → Check WiFi and retry

❌ "API rate limit"
   → Too many requests
   → Wait 1 minute and retry
```

**Solution:**
- Review failed files in results dialog
- Fix the issues (rescan, better photo, etc.)
- Upload failed files individually or in a new batch

---

### Problem: App seems frozen

**Don't Panic!**
```
✅ Processing might be at a heavy file
✅ Check progress counter - is it moving?
✅ Wait 10-15 seconds
```

**If truly frozen:**
1. Tap Cancel button
2. Close and reopen app
3. Try smaller batches (10 files at a time)

---

### Problem: UI is laggy

**Check Device:**
- Low-end device? → Process 5-10 files at a time
- Many apps running? → Close unused apps
- Low memory? → Restart device

**Adjust Settings (Future Feature):**
```dart
// Developer can tune these
maxParallel: 2,  // Reduce from 4
memoryCleanupDelay: 500ms,  // Increase from 200ms
```
